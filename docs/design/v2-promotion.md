# v2 转正（2.0）方案

> 这份是**决策与落地清单**：2.0 到底改什么、不改什么、怎么验证、出错怎么退。
> 不含客户信息与本机路径。

## 1. 一句话

2.0 不是功能翻倍，而是**默认入口换代 + 兼容层**：不带参数进来就是新外壳，
老界面退到 `--v1`，保留若干个版本。

## 2. 入口矩阵

| 调用方式 | 1.4.x | 2.0 |
|---|---|---|
| `python -m ulpp` | 老界面 | **新外壳** |
| `python -m ulpp --v2` | 新外壳 | 新外壳（保留为等价别名，老脚本不会坏） |
| `python -m ulpp --v1` | — | 老界面 |
| `python -m ulpp --lang en` | 老界面 | 新外壳（英文） |
| `python -m ulpp --help` / 带其它参数 | 命令行 | 命令行（不变） |
| `ulpp.exe` 双击 | 老界面 | 新外壳（同一个 `packaging/entry.py`，改默认分支即可） |

关键：源码和 exe 共用 `ulpp.__main__.main()`，所以**只改这一处**，两条路一起换。

## 3. 打包收敛

- 启动器改名：`start.bat`（默认进新外壳）+ `start-classic.bat`（`--v1`）。发版说明里原来写的
  `启动 v2.bat` 在 zip 里根本不存在，一并修正
- `packaging/ulpp_v2.spec` **不改名**：CI、AGENTS、README 共 6 处引用，改名收益小于风险，
  留给以后单独做一次打包整理
- 删掉 `packaging/label_sheet.spec`、`packaging/label_sheet_onedir.spec` 两个历史残留（违反「不许出现 label_sheet」）
- 全功能包附件说明里的 exe 体积由「约 36 MB」改为「约 39 MB」（实际 38.8 MiB）

## 5. 首次启动引导

- 判定「首次」：从来没有保存过胶纸（`sheets.json` 无 `sheets`）且没有自定义模板
- 行为：新外壳起来后自动打开「初次校准」，并突出「有扫描仪 / 没有扫描仪」二选一
- 可跳过：校准窗口本来就有「跳过 / 稍后」的出口，跳过即视为完成首次引导（写一个标记，别每次启动都弹）
- 标记文件：`<state_dir>/first_run_done`（测试可用 `ULPP_STATE_DIR` 指走）

## 6. 试打自动纠偏

现状：打完校准页要人肉量偏移、手填左右/上下（`PrinterProfile.offset_x_mm/offset_y_mm`）。

目标：打一张「校准页」→ 扫描 → 程序自己算出偏移 → 写回配置。

接口（新模块 `src/ulpp/offset_calib.py`，纯逻辑，可单测）：

```python
@dataclass
class OffsetResult:
    dx_mm: float          # 打印内容相对纸的横向偏移（正 = 偏右）
    dy_mm: float          # 纵向（正 = 偏下）
    confidence: float     # 0~1
    warnings: List[str]

def make_page_pdf(grid: GridSpec, path: str, dpi: int = 300) -> str:
    """生成校准页：按 grid 的节距/相位画格子细线框 + 四角角标，供打印在普通纸上。"""

def measure_offset(image_path: str, grid: GridSpec, dpi: Optional[float] = None) -> OffsetResult:
    """从扫描/照片里量出实测位置与期望位置的差。"""
```

写回规则：`offset_x_mm = -dx_mm`、`offset_y_mm = -dy_mm`（`PrinterProfile` 的语义是「把内容往右/往下移多少」，
打印偏右就要往左挪），并受现有 ±5 mm 上下限约束。

精度预期：扫描仪 ±0.1 mm；手机拍照受纸翘影响，±0.3~0.5 mm（与量纸同源）。置信度低时不给数字，只提示重扫。

## 7. 测试计划

- 新增 `tests/test_offset_calib.py`：合成图（已知平移）→ 量回来误差 ≤ 0.2 mm；
  极端情况（全黑、空白、非 A4 长宽比）要返回低置信度而不是抛异常
- 新增 `tests/test_entrypoints.py`：入口矩阵（`--v1` / `--v2` / 无参数 / `--lang`）用 mock 断言进哪个界面
- 首次引导：有/无标记文件两种情况
- 现有 782 条必须全绿；`test_constraints` 里的命名与离线约束不能破

## 8. 出错怎么退

- 入口切换只改 `__main__.py` 一个分支，回退 = 恢复那几行
- 首次引导有标记文件，删掉标记即可重现
- 自动纠偏只是「建议值」，写回前在界面上显示算出来的数字，用户可以不改

## 9. 手工验收清单（发版前自己过一遍）

1. 双击 exe / `python -m ulpp` → 直接是新外壳
2. `python -m ulpp --v1` → 老界面，功能正常
3. `python -m ulpp --help` → 命令行帮助，和以前一样
4. 删掉 `sheets.json` 后首次启动 → 自动弹校准；跳过后再启动不再弹
5. 内容页：加 3 个 PDF，列表能看到 3 条，选中一条移除，剩 2 条
6. 打一张校准页 → 扫描 → 自动纠偏给出偏移数字，接受后配置里能看到
7. 1366×768 分辨率下窗口完整可见、按钮不被裁
8. 中 / EN 各走一遍三站流程
